# ShopKart+ Advanced Frontend

React + Vite frontend-only e-commerce UI.

## Included
- Responsive desktop/tablet/mobile UI/UX
- Auto-swiping offer banner with 3 image offers, arrows and dots
- Search-as-you-type: title, description, brand and category matching
- Category filters and category browser
- Product detail pages
- Related products
- Wishlist persistence
- Cart drawer, quantity controls and remove
- Working frontend checkout and order history
- Demo authentication using localStorage
- Toasts, empty states and responsive layouts
- Frontend API rate limit (40 requests/minute)
- DummyJSON product API
- No backend/database

## Run
npm install
npm run dev

## Production note
Because this is frontend-only, authentication, orders and rate limiting are browser/demo features. Real security/rate limiting must be enforced server-side when a backend is added.


### Advanced updates
- INR pricing (demo conversion from API USD prices)
- Google, Apple and AI Cart sign-in buttons (UI demo; connect real OAuth provider for production)
- Animated buttons, cards and navigation icons
- Amazon/Flipkart-style order cancellation flow with cancelled status
